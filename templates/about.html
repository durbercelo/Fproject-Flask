О проекте

FProject — учебное веб-приложение, созданное с использованием Python и Flask.

Что это такое?

Этот проект представляет собой небольшое веб-приложение для просмотра обзоров и рецензий книг.

Пользователи могут зарегистрироваться, войти в свой аккаунт и получить доступ к персональной странице.

Используемые технологии

Python
Flask
SQLite
HTML / CSS
Flask-Login
SQLAlchemy
